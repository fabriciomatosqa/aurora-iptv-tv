# Hisense VIDAA — access required

Not an installable package. No complete open public TV SDK and distribution workflow has been verified for this project.

Before implementing or promising compatibility:
1. Request official VIDAA developer/partner access.
2. Obtain supported application package format and installation/testing procedure.
3. Verify input, storage, media playback, codecs and security APIs.
4. Complete an authorized device/simulator proof.
5. Verify store distribution contract and region policy.

Avoid unofficial TV modifications, security bypasses and unsupported sideloading. The shared TV interface can be adapted once official platform requirements are confirmed.
